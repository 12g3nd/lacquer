# Installing Lacquer on Windows

Lacquer is built as a Windows 11 x64 optimized client.

## Installation Options

### Installer (Recommended)
1. Download the `Lacquer Setup x.x.x.exe` from the Releases page.
2. Run the installer.
3. Lacquer will automatically install and launch.
4. SmartScreen may warn you that the publisher is unverified (since this is a personal open-source build). You can click "More info" > "Run anyway".

### Portable
1. Download `Lacquer x.x.x.exe` (Portable).
2. Run it from anywhere on your system.

## Updating
Auto-update is intentionally disabled in Lacquer v1 to prevent accidentally downgrading or cross-updating to Pear upstream releases.
To update, simply download the latest installer or portable executable from the Releases page and run it. Your data is perfectly safe.
