# Lacquer

Lacquer is a personal/public fork of [Pear (YouTube Music Desktop App)](https://github.com/pear-devs/pear-desktop) designed specifically as a highly polished, Windows 11 x64 daily-driver.

> **Disclaimer:** This project is not affiliated with Google or YouTube. It is a community-driven desktop shell for the YouTube Music service.

## Features
- **Windows-First Optimization**: Designed and optimized primarily for Windows 11.
- **Shared Session Continuity**: Seamlessly shares your existing Pear `userData` (YouTube Music) session, so you don't need to log in again.
- **Refined Aesthetics**: Polished UI, typography, and album-reactive effects tailored for desktop usage.

## Upstream Relationship
Lacquer stays closely in sync with the excellent foundation built by the `pear-devs` team. We aim to preserve upstream features, plugins, and reliability while implementing our specific aesthetic and Windows-focused optimizations. See [Upstream Strategy](docs/lacquer/UPSTREAM_STRATEGY.md) for more details.
